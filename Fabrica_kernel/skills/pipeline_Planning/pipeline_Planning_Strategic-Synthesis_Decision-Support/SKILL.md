# Pipeline Skill: Strategic Synthesis & Decision Support

## 1. Overview & Context
This skill completes the **Planning** stage of the Fabrica 4-Stage Looped Pipeline (`Drafting -> Planning -> Execution -> Delivering`).
It synthesizes findings from scoping, research, and analysis into executive summaries, risk audits, strategic roadmaps, Actionable Strategic Plans, and Interactive Decision Matrices.

## 2. Phase Operational Rules
- **Loop Status**: Non-loop final stage of Planning.
- **Inputs**: Scoping, Deep Research, and Data Analysis outputs from `Sources`.
- **Outputs**: Actionable Strategic Plan, Interactive Decision Matrix in `Sources/Strategic Synthesis & Decision Support`.

## 3. Step-by-Step Workflow
1. **Cross-Domain Synthesis**: Combine market research, technical requirements, and data metrics into a cohesive strategic narrative.
2. **Decision Matrix Formulation**: Build a multi-factor trade-off matrix scoring ROI, risk, effort, and business impact.
3. **Roadmap & Architecture Blueprint**: Define exact tasks, system boundaries, and code specifications for the Execution stage.
4. **Register Source Item**: Save strategic synthesis artifacts under `Sources -> Strategic Synthesis & Decision Support`.
