# Pipeline Skill: Execution Generation — Assets

## 1. Overview & Context
Handles visual design asset generation, icon/illustration creation, UI mockup generation, and structured PDF/doc styling under `Deliverables/Executions`.

## 2. Operational Rules & Subroutines
- Ingests visual specifications from Strategic Synthesis or Discovery scoping.
- Generates clean, crisp visual representations, vector graphics, or structured document templates.
- Registers generated assets in `Deliverables -> Executions`.
